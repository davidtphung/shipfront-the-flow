# THE FLOW

Public Shipfront website. Warehousing and fulfillment for eCommerce brands.

You grow your store. Shipfront runs the fulfillment behind it.

Live customer copy is taken from [myshipfront.com](https://www.myshipfront.com/). This cut does not invent pages, pricing, phone numbers, logos, or performance claims.

## Pages

- Home: `index.html`
- Get a Quote: `get-a-quote/`, `quote/`, `quote.html`
- Contact: `contact/`

The quote form is a client-side preview. It does not post to Squarespace or a CRM.

## Run locally

```bash
python3 -m http.server 43147 --bind 127.0.0.1
```

Then open `http://127.0.0.1:43147/`.
